# Chainlink CRE: friction log (written as it happened)

1. **Monad is missing from the skill's embedded tables.** `chainlink-cre-skill` (v0.0.24) `chain-selectors.md` has no Monad rows. The live forwarder directory page does: selector `monad-testnet`, MockKeystoneForwarder (simulation) 0xB9F79d86...d192, KeystoneForwarder (production) 0xF8344CFd...4482; both have code on chain. Cost: a WebFetch round trip; suggest adding Monad (143 / 10143) to the embedded table.
2. **`zod .url()` fails inside the workflow's config parser, with a misleading error.** Config validation ran in the QuickJS runtime and failed with `{"validation":"url","code":"invalid_string","message":"Invalid url","path":["perplApi"]}` for a perfectly valid https URL (no `URL` global there). Fix: regex. The skill says QuickJS lacks Node built-ins but does not mention `URL`.
3. **`cre workflow simulate` can fail with a transient auth error.** Once: `authentication required: credential validation failed: authentication failed: unable to retrieve organization info. Your account may not be fully set up yet — please try again in a few minutes`. Retrying 20 s later worked. The message suggests a broken account, which it was not.
4. **The mock forwarder cannot authenticate the workflow.** MockKeystoneForwarder does not verify DON signatures, so a receiver can only check `msg.sender == forwarder`; anyone can call the mock with any report/metadata. Our design therefore never trusts report content: the tape re-reads the Perpl oracle itself and the settler verifies every claim against the tape (disputable). Worth a line in the docs for receiver authors targeting simulation.
5. **`--broadcast` bills the full gas limit on Monad.** Monad charges the gas limit, not gas used. A report with an 800,000 limit cost 0.0816 MON for a ~120k operation. CRE has no gas estimate step for `writeReport`; I now size `gasConfig.gasLimit` from measured costs (tape.sample ~118k per market + overhead). An optional `estimate` mode would save testnet MON.
6. **Quotas worth knowing up front:** 15 HTTP requests and 15 EVM reads per run, cron minimum 30 s, 5 min per run (docs.chain.link/cre/service-quotas). Multicall3 through `callContract` keeps reads under the cap; the scaffold's generated sample doesn't hint at this.
7. **CLI not on PATH in non-interactive shells.** `cre init` appends to ~/.zshrc only; automation must call ~/.cre/bin/cre.
8. **`cre init` scaffold is Sepolia-only** (project.yaml targets use ethereum-testnet-sepolia). Fine, but a `--chain` flag would save the manual edit; the simulation output also ends with a "Ready to deploy?" nudge although deployment access needs a commercial call (declined; simulate-only).
9. **Good:** `cre workflow simulate --broadcast` really worked first time on Monad testnet; the compile + simulate loop is fast (~2 s).
